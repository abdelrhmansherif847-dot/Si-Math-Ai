# SI MATH AI — "THE AI COURT"
# THE PERFORMANCE PACKAGE — F-script · what every character is thinking, every moment

**Rebuilt to the LOCKED script (F01–F29, `14`) under Law 17.** The old 19-line dialogue package is
superseded; its surviving decisions (the visual verdict, the Laws cadence) are carried forward here.

**How to use this document:** before generating any take, read the shot's row and answer the only
question that matters — *what is every character thinking in this exact moment?* The THINKING
columns are the take's true content. The line is what escapes from it. **THE REACTION column names
the response that must outlive the line** — if that reaction isn't in the take, the take failed,
whatever the mouth did. Camera moves cite their emotional motive; a move that can't name one is cut.

The three inner lives governing every row (full charter in `11`):
**JZ already knows the verdict — he is waiting to see if anyone else can reach it. · LZ never
doubts — he argues so everyone understands. · The REPS are slowly realizing that solving is not
teaching — on their faces first.**
